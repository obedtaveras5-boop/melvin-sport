# Melvin Sport 🛍️

Tienda en línea de calzado, ropa y accesorios deportivos, creada por [tu nombre].

🔗 **Ver la tienda:** https://melvin-sport.vercel.app

## Qué incluye
- Catálogo con categorías, filtros y búsqueda
- Carrito y pedidos
- Panel de administración para productos, pedidos, cupones y reseñas
- Diseño adaptado a celular

## Tecnologías
Node.js, Express, PostgreSQL (Neon), Vercel
